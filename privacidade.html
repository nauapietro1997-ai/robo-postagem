Política de privacidade

Robô de postagem Nauã Pietro · atualizada em 22/11/2026

Quem usa

A ferramenta é usada só pelo dono do canal @naua.pietro, na própria conta Google dele. Nenhuma outra pessoa faz login nela.

Que dados do Google ela acessa

Com a autorização do dono, ela usa a API do YouTube para enviar e agendar vídeos do próprio canal, criar e preparar as transmissões ao vivo do próprio canal e ler o estado desses vídeos e transmissões.

Onde ficam os dados

A chave de acesso fica guardada só no computador do dono. A ferramenta não tem servidor próprio, não guarda dados em nuvem, não vende, não compartilha e não usa os dados para anúncios.

Dados de outras pessoas

Ela não coleta nem guarda dados de espectadores ou de qualquer outra pessoa.

Regras do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como cancelar

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.

Contato

Pelo canal youtube.com/@naua.pietro ou pelo Instagram @naua.pietro.

English summary: this personal tool is used only by the owner of the YouTube channel @naua.pietro. It uses the YouTube Data API to upload and schedule his own videos and manage his own live broadcasts. Tokens are stored only on his computer; no data is sold, shared or used for ads, and no data from other people is collected. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
